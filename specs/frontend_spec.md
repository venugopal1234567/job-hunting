# RemoteHunter Frontend Specification

## Tech Stack
- **Framework**: React 18 + Vite + TypeScript
- **Styling**: Tailwind CSS + Custom Dark Glassmorphism Theme (Custom modern UI components)
- **Icons**: Lucide React
- **State & HTTP**: React Hooks + Fetch / Axios API Client

## User Flows & Screens

### 1. Dashboard View
- Header banner showing overall stats (Total Matched Jobs, Active Target Skills, High ATS Matches > 80%).
- Filter bar:
  - Multi-select dynamic skills tag selector.
  - "Posted within" dropdown (24 Hours, 3 Days, 7 Days, 30 Days).
  - Country / Location filter text input.
- Responsive Grid/List of Job Cards sorted by ATS Score or Posting Date.
- Job Card details: Company logo placeholder, Title, Salary range, Location, Scraped Source Badge, Top Matched Skills, ATS Score indicator.

### 2. Job Detail & AI ATS Analysis View (Slide-over / Modal)
- Full job description view.
- **AI ATS Match Panel**:
  - Radial score wheel (0-100%).
  - Matched vs. Missing skills breakdown pills (Green for matched, Amber for missing).
  - Actionable Resume Improvement Bullet Points generated by Gemma 4.
  - Interactive Skill Gap Questions with quick-answer notes for interview preparation.

### 3. Resume & Settings Workspace
- Drag-and-Drop Resume File Uploader (.pdf / .txt).
- Live skill parser display allowing candidates to add/remove custom skill badges.
- Background Scraper configuration panel (add/edit remote job board RSS/API endpoints).
